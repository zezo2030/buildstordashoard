# Build Store — لوحة التحكم (Admin Dashboard)

لوحة تحكم ويب عربية (RTL) لإدارة منصة Build Store بالكامل، تعمل على نفس مشروع Supabase الخاص بالتطبيق.

## الأمان

- الدخول بحساب بريد/كلمة مرور دوره `admin` في جدول `profiles` — أي حساب آخر يُسجَّل خروجه فورًا.
- الحدود الفعلية هي سياسات RLS (`app.is_admin()`) — اللوحة تستخدم مفتاح `anon` العام فقط، و`SERVICE_ROLE` لا يصل للمتصفح أبدًا.
- عمليات المال والحالات (اعتماد السحب، التسويات، البث) عبر دوال `admin_*` ذرّية في الداتابيز.

## التشغيل

```bash
npm install
npm run dev        # http://localhost:5180
```

القيم الافتراضية للاتصال مضمّنة في `src/lib/supabase.ts` (مشروع Build Store). للتبديل لمشروع آخر أنشئ `.env`:

```
VITE_SUPABASE_URL=https://<project>.supabase.co
VITE_SUPABASE_ANON_KEY=<publishable-or-anon-key>
```

## ميجريشن لوحة التحكم (مطلوب مرة واحدة)

بعض العمليات تتطلب دوال `admin_*` — طبّق الملف التالي من Supabase SQL Editor:

```
docs/buildstoresupabase/supabase/migrations/20260809145230_admin_console.sql
```

قبل تطبيقه تعمل اللوحة كاملة عدا: **اعتماد** طلبات السحب (الرفض يعمل)، التسويات اليدوية على المحافظ، الإشعار الجماعي، وحقول الكريديت (تظهر الصفحة إرشادات التطبيق). تفعيل البائعين يعمل قبل الميجريشن عبر كتابات RLS مباشرة، وبعده يصبح ذرّيًا عبر `admin_activate_seller`.

## كلمات المرور

- **كلمة مرورك أنت:** صفحة «حسابي» (`/account`، أو اضغط اسمك أسفل القائمة الجانبية) — تتطلب كلمة المرور الحالية.
- **كلمة مرور مستخدم:** صفحة «المستخدمون» ← زر «كلمة المرور». تعمل عبر Edge Function
  `admin-set-password` لأن `SERVICE_ROLE` لا يجوز أن يصل للمتصفح.

الدالة تتحقق من دور المُنادي في الداتابيز (لا من الطلب)، وتفرض 8 أحرف كحد أدنى،
و**تمنع أي أدمن من تغيير كلمة مرور أدمن آخر** — كل أدمن يغيّر كلمة مروره بنفسه.
كل عملية تُسجَّل في `audit_log` (بدون أي قيمة لكلمة المرور).

التغيير فوري ولا يُرسَل بريد للمستخدم — تسليم كلمة المرور مسؤولية الأدمن.

> ملاحظة تشغيلية: أي مستخدم أُنشئ بإدراج SQL يدوي في `auth.users` لازم أعمدة التوكن فيه
> (`confirmation_token`, `recovery_token`, `email_change*`, `phone_change*`, `reauthentication_token`)
> تكون نصوصًا فارغة `''` لا `NULL`، وإلا يفشل تسجيل الدخول وإدارة الحساب برسالة
> «Database error loading user».

## البنية

- Vite + React 19 + TypeScript + Tailwind v4 (RTL، خط Tajawal، توكِنز من `mobile/src/theme/tokens.ts`)
- TanStack Query للبيانات + `supabase-js` مع ترقيم `range()` في كل القوائم
- أنواع الداتابيز في `src/types/database.ts` (نسخة من الموبايل — حدّثها بـ `supabase gen types`)
